Deadline Rescue 🚀

About the Project:
Deadline Rescue is a beginner-friendly, terminal-based Python application designed to help students manage their assignments, practicals, exams, and other important deadlines. It helps users organize tasks, identify priorities, and keep track of pending work so they can stay organized and avoid missing deadlines.

Features:
- Add new tasks and automatically assign priorities.
- View pending and completed tasks.
- Mark tasks as completed.
- Search, edit, and delete tasks.
- Receive deadline alerts.
- View task statistics.
- Save tasks so they remain available when the program is reopened.

Technologies Used:
- Python
- File handling
- Lists, loops, functions, and conditional statements

Purpose:
This project was created as a practical learning project to improve Python programming skills and demonstrate how programming can solve everyday problems.

How to Run
Requirements:
- Python 3 installed on your computer.

Steps:
1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run the following command:
python Deadline_Rescue.py
4. Follow the on-screen menu to manage your tasks.

Note:
Task data is stored locally in text files created by the program. Keep these files in the project folder when you want to retain your saved tasks.
